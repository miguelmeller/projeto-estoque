 Projeto de Estoque

Esse é um sistema de estoque simples na linguagem python com as seguintes opções:

Opcão 1 - O usuário adicionar um novo item pedindo o nome, quantidade e localização

Opcão 2 - Mostra todos os itens que tem no estoque, quantidade, localizção e id

Opção 3 - Busca o item por ID e exibe na tela

Opção 4 - O usuário escolhe o item por ID e atualiza a quantidade

Opção 5- Pede o ID para excluir o item

Opção 6 - Essa opção mostra os produtos que estão abaixo de 5 e pede para abastecer o estoque

Opção 7 - Encerra o programa
